# Telegram Mini App «Аптека»

Каталог товаров + корзина + оформление заказа прямо в Telegram.  
После заполнения формы заказ уходит в Битрикс24 как лид.

## Как использовать
1. Откройте бота [@arzonaptekabot](https://t.me/arzonaptekabot)
2. Нажмите «Открыть приложение»
3. Выберите товары → заполните имя и телефон → отправьте заказ

## Развёртывание
Статика хостится на GitHub Pages.  
В `app.js` замените `BX_WEBHOOK` на свой из Битрикс24.
